本目录为现有 `20260825` 之外的两个训练种子 `20260826`、`20260827` 提供隔离入口。当前只有代码；没有复制数据、生成检查点、启动训练或形成新实验结果。

| 组别 | 训练定义 | 预算 | 每组训练 |
| --- | --- | --- | --- |
| G1 | 图文匹配 BCE，从原始 ALBEF 初始化 | 1%、5%、10%、20%、30%、100% | 1600 步 |
| G2 | 对应种子 G1 的 `best.pt` → BCE + 自定义 Pair-USA | 同上 | 另加 1600 步 |
| G3 | 对应种子 G1 的 `best.pt` → BCE + OT | 1%、5%、10%、20%、30% | 另加 1600 步 |
| G4 | 对应种子 G1 的 `best.pt` → BCE + Pair-USA + OT | 同 G3 | 另加 1600 步 |

100% 没有无标签池，G3/G4 不适用。每种子共 22 个学生实验，另有六个按预算训练的 USA 教师；不训练历史队列里的独立 B 学生。G2/G4 使用本种子的教师，绝不借用 `20260825` 教师。

数据构造随机种子仍是 `20260825`：沿用同一 L/U 划分、完整 blind caption、已固定的随机异病例负例表和 400 图验证表。新增的两个数字只作用于训练随机流（模型初始化、采样与增强等）。这使两次新训练的输入完全一致，但随机弱负例仍可能是假负例；不进行独立测试集评估。

## 复现与解释边界

- G1 与 G2/G3/G4 不等训练算力：后面三组都有额外 1600 步。它们彼此都是从同种子 G1 最佳验证权重开启新的 1600 步阶段。
- 对每个新种子，A/B 模板的 B 配置仅用来给教师及 G2/G3/G4 继承相同超参数；没有 B 学生结果。验证选择模型依然使用原 400 图验证集。
- 现有 `20260825` 队列在不同预算之间串行消耗随机状态；新入口跳过独立 B 学生，预算间随机状态消耗量因此不同。模型头初始化和显式逐步采样仍由各自训练 seed 决定，但新旧三个种子不能声称逐随机数调用完全同构。这是复现报告里应注明的实现差异。
- G1/G2 所复用的历史训练器断点不保存完整 RNG 状态；中断续跑可以恢复模型、优化器、scaler 与步数，却不能保证与不中断时逐位一致。G3/G4 断点保存 RNG。若将“逐位复现”列为论文要求，需要先单独审核并修订新种子训练器，再开始新训练。
- 此脚本是新入口的静态实现；正式运行前建议在独立环境完成 CPU 与真实 GPU 的初始化、梯度、断点工程核验。本轮只做了语法检查，没有进行这些核验，也没有运行任何实验。
