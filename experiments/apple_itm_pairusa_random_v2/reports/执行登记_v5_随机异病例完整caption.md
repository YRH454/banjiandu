# 苹果图文匹配 BCE / Pair-USA：v5 执行登记

日期：2026-09-29。用户已明确修改负样本方案：不再采用第 1、4 类逐图语义排除与微小细节核验作为本轮前置门槛；处理第 2、3 类程序问题，并允许全部负例随机使用其他病例的完整 caption。本登记执行用户最后提出的简单方案，不等待重复批准。

## 本轮采用的负例

- 正例 `(I_i, T_i)`：本图与其原始 blind caption。
- 负例 `(I_i, T_j)`：保持图像不变，caption 来自另一 image ID 的完整原始 blind caption，二分类标签为 0。
- 不做疾病名替换、不插入或删除否定、不改写症状、叶形或背景，不经过旧临床子句解析器。因此旧解析器的否定误判和局部编辑越界不会进入这一轮。旧代码及失败记录保留，不宣称旧算法已修好。
- 随机负例不按疾病标签或人工视觉判断筛选；可能仍与图像语义相近。它是按病例身份随机错排的弱负例，不是经过视觉确认的语义矛盾金标准。
- 排除同 image ID、完全相同 caption、完全相同图像文件的直接配对。疾病标签只保留审计字段，不参与模型目标或抽样决策。

## 划分、可见性和固定随机化

- 沿用已登记的 13,373 训练、1,490 验证、3,715 测试图划分，以及六个嵌套训练预算。所有源文件只读。
- 预算按 1%、5%、10%、20%、30%、100% 顺序制表。每次只读取新增合法 L 图像的 caption，不能从该预算 U 或验证/测试取负文。
- 为同时满足“同一图跨预算保持同一个负文”和“每条 caption 正负各出现一次”，在各预算新增的图像批次内做固定随机无自配排列，已有图像的配对不变。它不是每次从完整扩大预算重新抽样，也不是强制跨病种。
- 固定种子仍为 `20260825`。每档 A/B 共用同一配对清单和采样次序。
- 验证集按固定种子从原验证 ID 中选 400 个锚图，完整 caption 仅在这 400 图内部随机错排；不与训练交换文字。它是随机错配验证集，不再称为人工审定 hard-negative 集。
- 不读取测试 caption，不执行独立测试集模型评估。

## 取代的旧门槛

v4 关于局部临床反事实、1% 逐图审定、至少 64 个视觉合格锚图、验证 400 图逐图视觉审定及相关人工假负率门槛，不适用于这个已获用户授权的随机配对版本。v1 的科学停止记录仍保留，不能改写为旧规则通过。

新版本采用结构性检查：来源哈希、预算可见性、split 互斥、无自配/相同 caption/相同文件、原文完整复用、正负文本多重集合完全相同、重叠 ID 跨预算稳定、A/B 清单一致、256-token 上限和图像文件存在。候选状态明确写为 `random_other_case_unverified`，绝不写成视觉审核通过。

每个清单中，完整 caption 在正负标签下各出现一次，因此任意只看 caption 的确定性分类器在该平衡清单上的 AUROC 必为 0.5（忽略数值误差）。以文本哈希和词表评分实测核验这一结构事实；这不证明模型已用视觉，也不证明随机负例没有语义假负。

## 模型与训练保持不变

- 六预算 × A（ITM-BCE）、B（ITM-BCE + 自定义 Pair-USA），共 12 个学生实验；运行顺序 5%、20%、1%、10%、30%、100%，各预算先 A，再独立教师和 B。
- ALBEF-4M 原始权重，384 像素，文本上限 256；视觉末两层 Q/V LoRA rank 4、alpha 8；融合跨注意力层 6–11 Q/V LoRA rank 8、alpha 16；单 logit 图文匹配头。
- 每步 16 个互异锚图、各一真一随机负文，32 图文对；每组 1600 步；单种子；AdamW 与预热/余弦学习率、Pair-USA 权重/预热、独立预算教师均沿用 v4 数值。
- Pair-USA 只使用 16 个正对关系，不把随机负文作为关系蒸馏目标。不使用疾病分类 BCE，不混入 DINO/Qwen 教师。
- 每 50 步保存完整续跑状态，每 100 步验证；成对准确率选 best、AUROC 决胜，阈值只由验证确定。随机错配结果与旧临床 hard-negative 或六病害分类结果不可直接比较。
- FP16 同一步溢出退避重试；共享图像前缀和冻结文本前缀缓存；一次仅运行一个 GPU 队列。数据/配置/代码/教师指纹必须一致才能恢复。
