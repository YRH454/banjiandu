# C：从 A 最佳权重开始的 BCE + 自定义 Pair-USA 再微调

用户于 2026-09-29 要求：“在我们A基础上加上USA吧，跑完B后在A的最佳权重下加上USA”。本分支不替换原独立初始化的 B。

## 范围及顺序

沿用六个预算，顺序 5%、20%、1%、10%、30%、100%，新增六组 C。原 random_v2 的十二组 A/B 正在运行，不中断、不修改其代码、配置、配对表、检查点或结果。原队列全部完成且 GPU 队列锁释放后，自动执行 C。开始前逐组确认对应 A、B 和教师已完成。

## 权重与优化

- 只从对应预算 A 的 `best.pt` 继承视觉 LoRA、跨模态 LoRA 与匹配头，共 34 个参数键。禁止使用 A 的 last.pt、其他预算 A 或 B 的学生权重替代。
- ALBEF 冻结部分继续加载同一份原始 ALBEF_4M.pth。A 最佳权重不含优化器和 scaler，因此这是 weights-only warm start，不声称精确恢复 A 的训练轨迹。
- Pair-USA 的 student_projection 两层共四个参数键及 log_student_temperature，共五个新键，使用原 B 的固定初始化方式；τ 初始为 0.07。只允许这五个键没有 A 来源，其他缺键、多键、形状或数值异常均拒绝。
- 每组额外训练 1600 步，新建 AdamW、FP16 scaler（初值 1024）与学习率日程。LoRA LR=1e-4，head LR=2e-4，wd=0.01，梯度裁剪=1；80 步 LR 预热后余弦衰减。
- 为避免额外改动，继承 B 的 USA 加权日程：新阶段前 100 步 λ=0，101—200 步升到 0.1。BCE 始终保留；不是只优化 USA。
- 新阶段采样步号从 1 开始，仍用 seed=20260825、同一固定配对表和增强算法。这是新的微调阶段，不把新增步号伪装成 A 原步号。
- 每步仍为 16 个正对锚图＋16 个同图随机错配负对；USA 只作用于 16 个正对的关系矩阵。每 50 步存 last，每 100 步验证，以 paired accuracy、AUROC 决胜选 best。

## 教师、数据与检查

复用对应已完成 B 所使用的独立教师 best.pt 和 positive_targets.pt，逐项核对 B result 登记的 SHA256、模型配置、原代码和数据指纹、图像 ID 顺序及 canonical/flip 视图，不复制改写教师检查点。

全部沿用 random_v2 的 blind caption、原文随机异病例负例、嵌套预算和固定 400 图验证集；不读取测试 caption，不运行独立测试集评估。随机负例仍为 random_other_case_unverified，可能存在语义相容的假负例。

新脚本仅在新进程内包装原模型构造器和教师入口，并复用原 run_student 的训练、验证和 FP16 同步重试逻辑；不会修改原文件。新代码、此登记、计划、原来源登记、对应 A best/result、B result 和教师文件哈希都进入 C 的配置和检查点 provenance。C 意外中断只从自己的完整 last.pt 恢复 optimizer/scaler/步数；来源变化即拒绝恢复。

新根有独占锁防重复等待器；执行期间还持有原队列锁防 GPU 队列重叠。后台等待期间不加载 ALBEF、不占用 GPU。只有 CPU 初始化/恢复检查通过，才能自动开始 C。

## 结果解释

C 的阶段步数单独报告，并显示 A 源最佳步数及两段训练路径长度。例如 5% A best=1500，则 C phase=1600 对应 3100 个沿继承路径的更新；原 A 虽完整执行 1600 步，但最后 100 步没有进入该 best 权重。实际总计算还包含原 A/B 已执行工作。

C 是新训练策略，不是原 B 的重跑；它比原 A 或 B 多用了优化步骤。没有新增“从 A best 继续 BCE 相同步数”的控制组，因此不能仅凭 C 提升宣称收益完全来自 USA。本次不自动扩展该控制组或其他新实验。
